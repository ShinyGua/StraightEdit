# StraightEdit: Efficient Low-Step Inversion-Free Text-Guided Image Editing (ACMMM 2026)

Official Implementation of **StraightEdit**.

StraightEdit is a text-guided image editing framework designed for efficient, low-step editing without inversion, aiming to deliver high-quality results with reduced computational cost.

> 🚧 This repository is under active development. Code, pretrained models, and detailed instructions will be released here.

## Highlights

- **Inversion-free** text-guided image editing
- **Low-step** editing process for improved efficiency
- Focus on strong edit fidelity and visual quality
